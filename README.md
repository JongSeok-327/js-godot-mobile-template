# JS Godot 모바일 게임 템플릿

**한국어** · [English](README.en.md) · [日本語](README.ja.md)

Godot으로 모바일 게임을 만들 때, **게임 내용만 채워 넣으면 되도록 나머지를 미리 다 만들어 둔 프로젝트**입니다.

---

## 이게 왜 필요한가요?

게임 하나를 만들려면 "게임 그 자체" 말고도 만들어야 할 게 잔뜩 있습니다.

- 처음 켰을 때 나오는 시작 화면과 버튼들
- 설정에서 소리 크기 조절하기
- 어디까지 했는지 저장하고 다시 불러오기
- 게임 중에 잠깐 멈추기
- 한국어 / 영어 / 일본어 바꾸기
- 화면이 뚝 끊기지 않고 부드럽게 넘어가기

문제는 이것들이 **어떤 게임을 만들든 거의 똑같다**는 겁니다. 새 게임을 시작할 때마다
처음부터 다시 만드는 건 시간 낭비죠.

집 짓는 것에 비유하면, 이 프로젝트는 **뼈대가 서 있고 전기와 수도까지 연결된 빈 집**입니다.
벽지 고르고 가구 놓는 일 — 그러니까 진짜 게임 내용 — 만 하면 됩니다.

## 지금 상태

- **게임 내용은 비어 있습니다.** 그게 여러분이 채울 부분입니다.
- 위에 적은 기반 기능들은 전부 만들어져 있고 동작합니다.
- 안드로이드에서 실제로 앱을 설치해 켜보고 확인했습니다.
- 자동으로 돌아가는 검사 121개가 전부 통과합니다.

## 무엇이 들어 있나요?

### 항상 켜져 있는 부품들

게임을 켜는 순간부터 꺼질 때까지 계속 살아 있으면서, 어느 화면에서든 불러 쓸 수 있는
부품들입니다. (Godot에서는 이런 걸 **autoload**라고 부릅니다.)

| 이름 | 하는 일 |
|---|---|
| **SaveManager** | 게임 진행 상황을 파일로 저장하고 불러옵니다. 나중에 저장 형식이 바뀌어도 **예전 저장 파일을 알아서 새 형식으로 바꿔주는** 장치가 들어 있습니다. |
| **Settings** | 소리 크기와 언어 설정을 기억합니다. 저장 파일과 **따로** 보관해서, 게임 기록을 다 지워도 설정은 남습니다. |
| **AudioManager** | 배경음악과 효과음을 담당합니다. 음악이 바뀔 때 뚝 끊기지 않고 자연스럽게 겹쳐 넘어갑니다. 게임을 멈춰도 음악은 계속 흐릅니다. |
| **SceneManager** | 화면 전환을 담당합니다. 화면이 어두워졌다 밝아지면서 넘어갑니다. |
| **Services** | 광고와 결제를 담당할 **자리**입니다. 자세한 설명은 아래에. |
| **EventBus** | 부품끼리 소식을 주고받는 통로입니다. 자세한 설명은 아래에. |
| **DebugTools** | 개발 중에만 나타나는 디버그 창입니다. 자세한 설명은 아래에. |

### 화면들

시작 화면 → 메인 메뉴 → 게임 화면이 이미 연결되어 있고, 그 위에 겹쳐 뜨는 창들
(일시정지, 설정, 게임 오버)도 만들어져 있습니다.

### 그 밖에

- **터치 입력** — 톡 누르기, 꾹 누르기, 끌기, 휙 넘기기를 알아서 구분해 줍니다.
- **한국어 / 영어 / 일본어** — 설정에서 바꾸면 게임을 껐다 켤 필요 없이 그 자리에서 바뀝니다.
- **한글·일본어 폰트 포함** — 폰트를 같이 넣어두지 않으면 기기마다 글자 모양이 달라집니다.
- **ObjectPool** — 총알처럼 계속 생겼다 사라지는 물건을 **버리지 않고 재활용**하는 장치입니다. 계속 새로 만들면 게임이 버벅이기 때문입니다.
- **안드로이드 뒤로 가기 버튼** — 게임 중엔 일시정지, 메뉴에선 종료로 동작합니다.
- **홈 버튼으로 나갔을 때** — 자동으로 멈추고 저장합니다. 안드로이드는 앱이 백그라운드에 있으면 언제든 꺼버릴 수 있어서, 나가는 순간 저장해두지 않으면 기록이 날아갑니다.

## 몇 가지 개념 설명

### EventBus — 부품끼리 소식 주고받기

"게임 오버가 됐다"는 사실을 여러 부품이 알아야 한다고 해봅시다. 서로를 직접 부르게 만들면
부품들이 거미줄처럼 얽혀서 나중에 하나만 고쳐도 여기저기 터집니다.

그래서 **게시판**을 하나 두었습니다. 알릴 일이 있으면 게시판에 붙이고, 궁금한 쪽이 게시판을
구독합니다. 서로를 몰라도 됩니다.

### Services — 광고와 결제의 "가짜 버전"

광고나 결제 기능은 구글에서 제공하는 별도 프로그램을 붙여야 진짜로 동작합니다. 붙이는 게
번거롭고, 붙이기 전까지는 테스트도 못 하죠.

그래서 **아무것도 안 하고 성공했다고만 대답하는 가짜 버전**을 넣어뒀습니다. 예를 들어
"광고 보고 보상 받기"를 누르면 광고 없이 곧바로 보상이 들어옵니다. 덕분에 진짜 광고를
붙이기 전에도 게임 흐름을 처음부터 끝까지 테스트할 수 있습니다.

나중에 진짜 광고를 붙일 때 **게임 코드는 한 줄도 고칠 필요가 없습니다.** 가짜를 진짜로
바꿔 끼우기만 하면 됩니다.

### DebugTools — 개발용 도구창

화면 왼쪽 아래 `DBG` 버튼을 누르면 열립니다. 프레임 속도 확인, 원하는 화면으로 바로 점프,
언어 바꾸기, 저장 기록 지우기를 할 수 있습니다.

**출시용으로 만들면 이 창은 통째로 빠집니다.** 실제로 빠지는지 확인까지 해뒀습니다.

## 시작하는 법

### 1. Godot 설치

[godotengine.org](https://godotengine.org)에서 **4.7.1** 버전을 받습니다.
(다른 버전에서는 안 될 수 있습니다.)

### 2. 내려받기

```bash
git clone https://github.com/JongSeok-327/js-godot-mobile-template.git
cd js-godot-mobile-template
```

### 3. 첫 준비 (한 번만, 꼭 해야 합니다)

```bash
GODOT=/Applications/Godot_4.7.1.app/Contents/MacOS/Godot   # 본인 설치 경로로

"$GODOT" --headless --path . --import
```

**이걸 왜 하나요?** 폰트나 번역 같은 파일은 Godot이 쓰기 좋은 형태로 한 번 변환해야
합니다. 변환 결과물은 용량이 크고 언제든 다시 만들 수 있어서 저장소에 넣지 않았습니다.
그래서 처음 받았을 때 직접 한 번 돌려줘야 합니다.

에디터로 프로젝트를 열어도 자동으로 됩니다.

### 4. 실행

```bash
"$GODOT" --path .            # 게임 바로 실행
"$GODOT" --path . --editor   # 에디터로 열기
./tests/run_all.sh           # 검사 돌려보기
```

## 내 게임 만들기

1. **게임 내용을 넣습니다.** `scenes/game/game.tscn`을 열면 `Gameplay`라는 빈 자리가
   있습니다. 거기 아래에 만드세요.
2. **새 화면을 추가했다면** `autoload/scene_manager.gd`의 `SCENES` 목록에 이름을 등록합니다.
   화면 파일 경로를 코드 여기저기에 직접 적지 마세요 — 나중에 파일을 옮기면 전부 찾아
   고쳐야 합니다.
3. **글자를 추가할 때는** `locale/translations.csv`에 한 줄 추가합니다. 세 언어를 한 줄에
   같이 적습니다.
4. **디자인을 바꾸려면** `ui/theme/default_theme.tres`에서 색과 모서리 둥글기만 고치면
   전체가 한꺼번에 바뀝니다.
5. **출시 전에** 앱 이름표(`com.jsgame.template`)와 아이콘(`icon.svg`)을 바꾸세요.
   ⚠️ 앱 이름표는 **스토어에 한 번 올리면 영영 못 바꿉니다.**

## 폴더 구조

```
autoload/   항상 켜져 있는 부품들
scenes/     화면들 (시작, 메뉴, 게임, 겹쳐 뜨는 창들)
ui/         디자인 테마, 재사용 부품
scripts/    광고·결제 자리, 터치 입력, 유틸리티
debug/      디버그 창 (출시 빌드에서는 빠짐)
locale/     번역 파일
assets/     폰트, 소리, 이미지
tests/      자동 검사
```

더 자세한 개발 규칙과 안드로이드 빌드 방법은 [`CLAUDE.md`](CLAUDE.md)에 있습니다.
