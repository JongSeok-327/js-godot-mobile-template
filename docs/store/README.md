# 스토어 등록 문서 골격

게임을 얹으면 `{게임}`·`{개발자}`·`{이메일}`·`{URL}` 를 채운다. kongkong·kongslash(`docs/store/`)가 채운 예다.

| 파일 | 어디에 쓰나 |
|---|---|
| `listing.md` | App Store Connect 앱 정보·버전 페이지 문구 (언어별) + 심사관 메모 |
| `privacy-policy.md` | 개인정보처리방침 — github.io 등 공개 URL 에 올려 앱 정보에 넣는다 |
| `support.md` | 지원 URL 페이지 |
| `app-privacy.md` | "앱이 수집하는 개인정보" 응답표 |
| `age-rating.md` | 연령 등급 설문 응답표 |
| `screenshots/<언어>/` | 1206×2622 (6.3인치 칸) 다섯 장 정도 |
