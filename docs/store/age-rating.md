# App Store 연령 등급 응답표

App Store Connect → 앱 정보 → 연령 등급 (7단계 설문). 판단이 걸린 것만 적고 나머지는 "없음/아니요".

| 질문 | 답 | 근거 |
|---|---|---|
| 1단계 · 사용자 생성 콘텐츠 | (닉네임이 남에게 보이면 예) | 신고 기능 필요 (가이드라인 1.2) |
| 1단계 · 광고 | (광고 SDK 면 예) | |
| 5단계 · 만화/판타지 폭력 | (때리고 베면 "드문" → 9+) | "없음" 으로 하면 실제와 달라 지적받는다 |
| 6단계 · 모의 도박 · 루트 박스 | (뽑기가 있으면 예) | |

7단계: 대한민국은 특정 기준(사행성 등)에 걸릴 때만 GRAC 등급분류번호가 필요하다. 키즈 카테고리는 고르지 않는다(제3자 광고 제한).
