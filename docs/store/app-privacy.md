# App Store "앱이 수집하는 개인정보" 응답표

**광고 SDK 가 수집하는 것도 적는다.** 제출 직전에 SDK 의 최신 안내를 확인한다
(AdMob: developers.google.com/admob/ios/privacy/data-disclosure).

| 데이터 유형 (Apple 분류) | 누가 | 실제 내용 | 용도 | 사용자에 연결 | 추적 |
|---|---|---|---|---|---|
| (예) 식별자 › 사용자 ID | 우리 서버 | 기기에서 만든 무작위 ID | 앱 기능 | 예 | 아니요 |
| (예) 사용자 콘텐츠 › 게임플레이 콘텐츠 | 우리 서버 | 점수 등 | 앱 기능 | 예 | 아니요 |
| 식별자 › 기기 ID | 광고 SDK | IDFV 등 (ATT 미요청 → IDFA 없음) | 타사 광고, 분석 | 아니요 | 아니요 |
| 사용 데이터 › 제품 상호작용 · 광고 데이터 | 광고 SDK | | 타사 광고, 분석 | 아니요 | 아니요 |
| 위치 › 대략적 위치 | 광고 SDK | IP 추정 | 타사 광고, 분석 | 아니요 | 아니요 |
| 진단 › 충돌·성능·기타 진단 | 광고 SDK | | 분석 | 아니요 | 아니요 |

ATT 팝업을 넣으면 기기 ID·광고 데이터의 "추적" 을 예로 바꾼다. 세이브(기기에만 저장)는 수집이 아니다.
닉네임은 "연락처 › 이름" 이 아니라 "기타 사용자 콘텐츠". 응답을 마치면 "게시" 해야 반영된다.
